\section*{PREFACE}
\addcontentsline{toc}{section}{Preface}

The volatility of gold prices has long been a central concern for investors, financial institutions, and individuals seeking to preserve their wealth. Accurate forecasting of gold prices not only supports smarter investment decisions but also provides measurable economic value in an increasingly data-driven financial landscape.

Motivated by the convergence of financial technology and modern machine learning infrastructure, our team developed \textit{X-AURUM} --- a fully automated Gold Price Forecasting System that integrates real-time market data acquisition, ML.NET-powered regression modelling, and enterprise-grade API delivery into a single cohesive platform.

The name \textit{X-AURUM} is derived from the Latin word \textit{aurum} (meaning ``gold'') and the prefix \textit{X}, symbolising the algorithmic, data-driven nature of the system. Rather than relying on human intuition, X-AURUM allows machine intelligence to analyse current market conditions and produce a precise price forecast automatically.

Within the scope of this report, the team implements and documents a complete end-to-end pipeline comprising: (1) automated data harvesting from the Binance public API; (2) model training using the LightGBM gradient-boosting algorithm via ML.NET; (3) deployment of a high-performance ASP.NET Core Minimal API with rate-limiting protection; and (4) containerisation and CI/CD automation via Docker and GitHub Actions.

We sincerely thank Dr.\ Nguyen The Vinh for his dedicated guidance and the constructive feedback that shaped this project. We also acknowledge the broader open-source community whose tools and libraries made this system possible.
